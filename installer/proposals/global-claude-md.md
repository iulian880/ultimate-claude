# Global working rules (ultimate-claude)

The user's explicit request takes priority. Follow the project's own conventions.
Speak Romanian with the user. Write code, configuration and commit messages in English.
Explain consequential decisions briefly. Give exact commands when a user action is needed.
Never claim done without current evidence. Name what was checked, the result and what remains open.
Use the project's verification commands. Preserve the original output for anyone reviewing the result.
When uc-core is enabled, use uc-core:uc-profile for routing and verification; an explicit profile wins.
For a long handoff, carry forward active criteria, decisions, evidence and the next action.
