# Choosing a component

Follow the user's request and project contract. Apply each rule when its trigger first occurs. Use the available skill by name. If unavailable, perform the indicated check directly and disclose the fallback.

- A decision depends on a library's API, options or version: use find-docs with Context7 (resolve the library, then query the relevant version). Use the configured Context7 MCP when the CLI is unavailable. Check the answer against the matching documentation and cite it. For a local defect, reproduce and inspect local code first. Use superpowers:systematic-debugging for an unexplained failure, and consult library docs only if an external API question remains.
- Work will cross sessions, machines or owners: use planning-with-files. Reuse existing plan, findings and progress records. Before handoff, record the active criterion, verified evidence with its platform, open questions and the exact next action. On resume, read them and recheck current state. A long task expected to finish here needs no extra files solely for its length.
- If the required result is unclear, clarify it. Use existing skills, project tools or built-in abilities when sufficient. When a concrete requirement exceeds them, use uc-core:product-discovery to find and check an additional skill. A concrete choice about an abstraction or dependency calls for uc-core:complexity-check. For costly architecture decisions the architect uses codebase-design and domain-modeling where applicable.
- Use a specialist when the deliverable requires its checks: accessibility-engineering for accessibility, browser-testing-with-devtools for browser reproduction, code-simplification for requested simplification. Use the corresponding document skill for an actual workbook, document, PDF or slide artifact. VBA source changes follow uc-excel:vba-workflow. Creating or improving a reusable skill calls for skill-creator and trigger examples.
- At STANDARD or STRICT completion use uc-core:delivery-report. For a requested PR summary, derive behaviour, executed checks and gaps from that evidence. If a confirmed failure recurs or was costly to diagnose, preserve its smallest reusable lesson in a regression test, existing project guidance or an ADR for a durable decision. Check that the lesson catches the original failure or answers the next decision. Skip a new record when existing coverage already does that.
